# Package Commands

Read this file when a workflow refers to package-local command setup. It maps published entrypoints; each command owns its own options and detailed behavior.

| Command                   | Purpose                                                                                                                                                                                                                                                                                                            | Source                                                     |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------- |
| `dev`                     | Generic Docker Compose wrapper for project-local `bin/dev` shims.                                                                                                                                                                                                                                                  | [`bin/dev`](./dev)                                         |
| `check-commit-scope`      | Reject mixed staged file categories unless explicitly overridden; a root `.commit-scope.json` can declare exact inseparable release groups.                                                                                                                                                                        | [`bin/check-commit-scope`](./check-commit-scope)           |
| `agent-guidance-audit`    | Read-only audit of a downstream repository's guidance.                                                                                                                                                                                                                                                             | [`bin/agent-guidance-audit.js`](./agent-guidance-audit.js) |
| `git-edit-commit`         | Backward-compatible entrypoint for scripted history edits.                                                                                                                                                                                                                                                         | [`bin/git-edit-commit`](./git-edit-commit)                 |
| `agent-rebase-edit`       | Non-interactive helper for rewording or editing older commits.                                                                                                                                                                                                                                                     | [`bin/agent-rebase-edit`](./agent-rebase-edit)             |
| `agent-worktree`          | Creates a conventionally located issue worktree, copies configured local files, and allows `direnv` when available.                                                                                                                                                                                                | [`bin/agent-worktree`](./agent-worktree)                   |
| `temporary-mcp-task`      | Run one confirmed child task with a temporarily enabled native OMP MCP server.                                                                                                                                                                                                                                     | [`bin/temporary-mcp-task.js`](./temporary-mcp-task.js)     |
| `github-pr-stack`         | Preflight a bottom-to-top GitHub PR stack and emit the `gh stack link` registration command.                                                                                                                                                                                                                       | [`bin/github-pr-stack`](./github-pr-stack)                 |
| `github-review-thread`    | Upvote/downvote, reply, and resolve review comments in the current repository.                                                                                                                                                                                                                                     | [`bin/github-review-thread`](./github-review-thread)       |
| `github-reviewed-files`   | Inspect exact PR file Viewed states; mark only explicitly approved reviewed paths with identity/head checks and fresh readback. See the [opt-in contract](../docs/references/github-tooling-reference.md#opt-in-reviewed-files-helper).                                                                            | [`bin/github-reviewed-files`](./github-reviewed-files)     |
| `check-title-case`        | Fail when a GitHub issue or pull request title is not title case.                                                                                                                                                                                                                                                  | [`bin/check-title-case`](./check-title-case)               |
| `github-headless-session` | Starts a disposable headed-to-headless GitHub browser session and prints a loopback CDP endpoint. The endpoint is not an authorization boundary; use a dedicated test account with repository-only access.                                                                                                         | [`bin/github-headless-session`](./github-headless-session) |
| `triage`                  | Capture read-only GitHub context, validate a structured assessment, and render an advisory preview. See the [contract and examples](../docs/references/ticket-triage-reference.md).                                                                                                                                | [`bin/triage`](./triage)                                   |
| `authorization-preview`   | Explain a browser handoff before an explicit HTTPS redirect; `--demo` previews the experience without leaving the local page. See the [request and lifecycle contract](../docs/references/authorization-preview-reference.md).                                                                                     | [`bin/authorization-preview`](./authorization-preview)     |
| `privilege-preview`       | Explain an operation before running any caller-selected command, as the current user or administrator. GPG signing and administrator checks are examples, not restrictions. `--demo` never authenticates or executes. See the [request and execution contract](../docs/references/privilege-preview-reference.md). | [`bin/privilege-preview`](./privilege-preview)             |
| `conventions-memory`      | Preview, export, or explicitly synchronize committed conventions into native Mnemopi memory. Requires Bun 1.4.4; see the [bootstrap contract](../docs/references/conventions-memory-reference.md).                                                                                                                 | [`bin/conventions-memory`](./conventions-memory)           |

`agent-rebase-edit` is the published rebase helper. `git-edit-commit` remains a compatible alias.

To allow a genuinely inseparable feature or release group without allowing unrelated mixed commits, declare each all-or-nothing group in the repository root:

```json
{
  "atomicGroups": [["src/feature.ts", "test/feature.test.ts", "docs/feature.md", "package.json"]]
}
```

The checker accepts only the exact declared paths. Partial groups or groups mixed with extra paths still fail.
