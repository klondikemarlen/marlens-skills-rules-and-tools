# Version-Aware GitHub Bug Reporting

## Task

Apply the [GitHub bug-reporting workflow](../docs/workflows/github-bug-reporting-workflow.md) to the fictional cases below. Supplied version identities and reproductions are scenario facts, not observations about a real tool. No case authorizes live external writes, upgrades, or implementation.

## Check

Run a bounded read-only OMP consumer against the canonical workflow, then the installed packaged fallback outside a project with local overrides. Ask for each case's destination, write/no-write decision, affected identities, evidence separation, unknowns, and minimal report or reason not to file. Add an authorization-negative control and a genuine new versioned recurrence on a covering issue; verify the consumer withholds unauthorized writes and reuses the covering issue rather than duplicating it. Report actual decisions, not matching phrases. Do not file fictional reports to demonstrate the workflow.
