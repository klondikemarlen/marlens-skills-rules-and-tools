# Guidance Examples

These outcome cases show the smallest useful difference made by one packaged skill, rule, or tool. They are not copyable templates: read the linked guidance before applying the pattern to a project.

- [`factory-traits-and-service-shape.md`](./factory-traits-and-service-shape.md) — reusable persisted relationship setup without per-test factory mutation.
- [`complexity-standards.md`](./complexity-standards.md) — self-contained, well-owned solutions instead of line-count optimization.
- [`agent-guidance-audit.md`](./agent-guidance-audit.md) — deterministic downstream guidance auditing instead of manual document inspection.
- [`rules-and-verifications.md`](./rules-and-verifications.md) — contextual guidance paired with a deterministic release backstop.
- [`project-aware-test-review.md`](./project-aware-test-review.md) — replayable semantic review of complete changed tests against local conventions and compliant siblings.
- [`test-assertion-focus.md`](./test-assertion-focus.md) — declared semantic review with ordinary-language local standards, native blocker/correction evidence, and count-free clean cases.
- [`dependency-test-ownership.md`](./dependency-test-ownership.md) — replayable decisions separating upstream API behavior, application-owned integration coverage, and version-scoped cutover proof.
- [`shared-standards-adoption.md`](./shared-standards-adoption.md) — direct shared-base inheritance with local deltas, missing-source/conflict boundaries, and replayable consumer proof.
- [`reader-focused-publication.md`](./reader-focused-publication.md) — separate required execution evidence from useful public communication, with replayable publication decisions.
- [`outcome-skills.md`](./outcome-skills.md) — memorable task intentions with bounded progress, evidence-backed simplification, and safe session closure.
- [`github-bug-reporting.md`](./github-bug-reporting.md) — current upstream defects, older released fixes, and integration/agent errors.
- [`keep-a-changelog.md`](./keep-a-changelog.md) — dedicated release history, registry publishing, and a deliberate local format exception.
