# PR Stack

Use the local `docs/workflows/pull-request-management-workflow.md`, then `agents/workflows/pull-request-management-workflow.md`, for project-specific policy. For creation and registration, see `Creating a GitHub Stack` there or the [packaged workflow](workflow.md). For changes to an existing stack, use [Propagating a Fix Through an Existing Stack](workflow.md#propagating-a-fix-through-an-existing-stack) unless local guidance provides a different procedure.
