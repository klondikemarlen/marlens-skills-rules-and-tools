# Pull Request Management

Use the local `docs/workflows/pull-request-management-workflow.md`, then `agents/workflows/pull-request-management-workflow.md`; otherwise use the [packaged workflow](workflow.md).

For PR screenshot capture or upload, also use the local `docs/workflows/upload-pr-screenshots-workflow.md`, then `agents/workflows/upload-pr-screenshots-workflow.md`; otherwise use the [packaged screenshot workflow](../../docs/workflows/upload-pr-screenshots-workflow.md). Resolve this route even when the local PR workflow has no screenshot link; preserve deliberate local policy and report conflicting instructions.
